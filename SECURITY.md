# Security policy

## Reporting a problem

Please don't report a security problem in a public issue. Write to
[contact@openfurqan.com](mailto:contact@openfurqan.com) instead, with "Security" in the subject, and
tell us:

- what is affected,
- how to reproduce it,
- what someone could do with it.

We'll reply to confirm we have it, keep you told while we fix it, and credit you if you'd like.

## What's covered

The live site at [openfurqan.com](https://openfurqan.com) and the `main` branch of this repository.
